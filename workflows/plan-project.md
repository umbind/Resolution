2. Write docs/PRD.md, docs/ARCHITECTURE.md (stack, data model, security rules, AI design with Hindi examples), docs/BACKLOG.md (milestones G1 to G5, tasks small enough for one session, each with acceptance criteria and tests), docs/RISKS.md, docs/UX_BENCHMARK.md, docs/DESIGN.md, docs/ENGAGEMENT.md, docs/USABILITY_TEST.md, and the first version of docs/AI_EVAL.md. Follow the "World-class UX benchmark" rules for the design research.
3. Create the Android project skeleton, the CI workflow, and the lint configuration only if nothing else is blocked. Initialise git.
4. Stop at Gate G0 with at most 3 questions. Include in the gate report a recommendation on whether the user should first run a small no-code validation with a real school or college group before heavy development, and what to measure.
