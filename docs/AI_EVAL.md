# AI Evaluation Suite: Resolution

This document contains 30 realistic educational cases from Uttar Pradesh (in Hindi, English, and Hinglish) used to evaluate Gemini prompt outputs across **Solution Coach**, **Duplicate Detection**, **Summarization**, and **Best Practical Plan**.

## 2. Automated Evaluation Script (`scripts/eval_ai.py`)
A standalone Python evaluator that feeds the 30 cases into the prompt templates and verifies:
1. **Safety pass rate:** 100% on cases TC-16, TC-19, TC-28 (No names, no politics, no minor data).
2. **Actionability score:** > 85% on feasibility and community role clarity.
3. **Language quality:** Natural Hindi without machine translation artifacts.
