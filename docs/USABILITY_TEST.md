# Usability Test Protocol: Resolution

**Target Audience:** 5 real participants in Uttar Pradesh (1 Parent, 1 Teacher, 1 Senior Student aged 16+, 1 Youth Volunteer, 1 Local NGO worker).  
**Device Environment:** Entry-level Android device (e.g. Redmi 9A / Realme C-series with 2GB/3GB RAM, 4G connection).  
**Primary Language:** Hindi.

---

## 1. Test Script & Tasks

### Task 1: First Impressions & Language Selection
* **Scenario:** "आप पहली बार ऐप खोल रहे हैं। अपनी भाषा चुनें और बिना खाता बनाए देखें कि आपके जिले में कौन-सी समस्याएं हैं।"
* **Target Time:** < 30 seconds.
* **Success Criteria:** User chooses Hindi, navigates through splash/onboarding, reaches Home Feed without being forced to log in.

### Task 2: Voice-First Issue Creation
* **Scenario:** "आपके गांव के प्राथमिक विद्यालय में हैंडपंप खराब है और बच्चे पानी नहीं पी पा रहे हैं। माइक बटन दबाकर बोलकर यह समस्या दर्ज करें।"
* **Target Time:** < 60 seconds.
* **Success Criteria:** User taps floating microphone, speaks the problem in Hindi, reviews transcribed text, selects district/block, and taps "दर्ज करें" (Submit).

### Task 3: Exploring & Evaluating a Solution
* **Scenario:** "होम स्क्रीन पर एक समस्या खोलें और उसके नीचे दिए गए समाधान को देखें। अगर आपको लगता है कि यह उपाय सही है, तो इसे 'समर्थन' दें।"
* **Target Time:** < 45 seconds.
* **Success Criteria:** User navigates to issue detail, reads structured solution card, taps upvote button, notes the counter increase.

### Task 4: Adding a Structured Solution
* **Scenario:** "किसी स्कूल में बिजली न होने की समस्या है। आप सुझाव देना चाहते हैं कि ग्राम प्रधान और SMC मिलकर सोलर लाइट लगवाएं। समाधान फॉर्म भरें।"
* **Target Time:** < 90 seconds.
* **Success Criteria:** User opens solution composer, inputs 'क्या किया जाएगा', 'कौन करेगा', अनुमानित खर्च, और AI Solution Coach से फीडबैक देखता है।

### Task 5: Sharing to WhatsApp
* **Scenario:** "इस समस्या और समाधान को अपने गांव के व्हाट्सएप ग्रुप में साझा करें ताकि दूसरे लोग भी जुड़ सकें।"
* **Target Time:** < 20 seconds.
* **Success Criteria:** User taps WhatsApp share icon, verifies the generated Hindi image preview card, and triggers the share sheet.

## 2. Post-Test Interview Questions (in Hindi)
1. ऐप में लिखी हिंदी कितनी आसान और स्वाभाविक लगी? क्या कोई शब्द कठिन लगा?
2. बोलकर समस्या दर्ज करना कितना आसान रहा? क्या आवाज सही पहचानी गई?
3. क्या आपको विश्वास हुआ कि इस ऐप पर आपकी समस्या को सही समाधान मिल सकता है?
4. ऐप में सबसे अच्छी चीज क्या लगी और सबसे ज्यादा उलझन कहाँ हुई?
5. क्या आप इस ऐप को अपने स्कूल या गांव के लोगों को सुझाएंगे?
